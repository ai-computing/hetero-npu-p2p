# 모델 계산 대조

동일 KONI 가중치의 Hugging Face FP32 eager attention을 CPU에서 실행했다. 각 backend가 생성한128개 토큰을 해당 backend의 다음 입력으로 강제하며 다음 토큰 선택을 비교했다. 서로 다른 생성 궤적이므로 task accuracy나 품질 동등성 시험이 아니다.

| 경로 | FP32 top1 일치 | 전체 위치 | 최대 선택 logit 차이 |
|---|---:|---:|---:|
| 이종 PD | 505 | 512 | 0.084780 |
| RNGD native | 508 | 512 | 0.081940 |
| ATOM vendor | 508 | 512 | 0.081940 |

PD 평균 KL(FP32→PD)은 질의별 quality.json에 기록했다. 세 경로 모두 서울을 수도로 답하지만, 기술 설명의 사실성은 이 수치 검사로 검증되지 않는다. EOS를 무시하고 지정 길이까지 생성하므로 생성문에는 후속 가상 대화가 포함될 수 있다. 속도 비교를 위해 세 경로에 같은 출력 길이를 요구했다.

새 입력 분포·긴 문맥·응용 정확도 및 단독 실행 대비 non-inferiority는 별도 평가가 필요하다.
